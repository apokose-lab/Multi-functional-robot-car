# 3D CAD Models – STL Files

This directory contains the mechanical 3D models designed for the Multi-functional Robot Car project using Onshape.

The models represent custom mounting components and mechanical parts developed to integrate the robot's electronic and mechanical hardware into a single platform.

## CAD Models

| File | Description |
|---|---|
| `Base.stl` | Main base structure of the robot |
| `ESP32 board mount.stl` | Mounting bracket for the ESP32 development board |
| `LiDAR mount.stl` | Mounting structure for the RPLIDAR C1 |
| `Motion Pro Mount.stl` | Mounting bracket for the Motion 2350 Pro controller |
| `Motor mount.stl` | Mounting component for the DC motors |
| `Robotic arm mount.stl` | Mounting structure for the 4-DOF robotic arm |
| `Servo horn mount.stl` | Mechanical adapter for servo horn attachment |
| `ULTRASONIC SENSOR MOUNT (1).stl` | Mounting component for ultrasonic sensors |
| `US Mount.stl` | Additional ultrasonic sensor mounting component |
| `Wire management part.stl` | Component for organizing and securing robot wiring |

## File Information

- **File format:** STL (Standard Tessellation Language)
- **Units:** Millimeters (mm)
- **CAD software:** Onshape
- **Purpose:** 3D printing, mechanical integration, and prototyping

## Notes

- All models are designed specifically for the Multi-functional Robot Car project.
- STL files are exported from Onshape and intended for manufacturing and physical assembly.
- These files contain the exported 3D geometry and are not directly editable as native Onshape documents.
